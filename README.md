# GLOBAL LIFE OUTREACH MINISTRIES (GLOM)

A static church website for Global Life Outreach Ministries — a vibrant community dedicated to spreading the gospel and transforming lives through worship, prayer, and outreach.

## Pages

- **Home** (`index.html`) — Hero section, about, service times, upcoming events, latest sermons, newsletter signup
- **About Us** (`about.html`) — Ministry story, mission, leadership team, beliefs
- **Giving** (`giving.html`) — Online giving options (tithe, offering, building fund), bank details
- **Contact** (`contact.html`) — Contact info, message form, prayer request submission

## Tech Stack

- HTML5
- CSS3 (with CSS custom properties for theming)
- Vanilla JavaScript
- Google Fonts (Playfair Display, Inter)

## SEO Features

- Unique `<title>` and `<meta name="description">` on every page
- Open Graph (`og:`) and Twitter Card meta tags for rich social sharing previews
- `rel="canonical"` links to prevent duplicate content issues
- JSON-LD structured data (`@type: Church`) for search engine knowledge panels
- Semantic HTML5 elements (`<header>`, `<section>`, `<footer>`)
- Descriptive `alt` attributes on all images
- Mobile-friendly viewport configuration
- `robots` meta tags for crawl control

Update the canonical URLs, OG image path, and placeholder data (address, phone, email) with your real information before deploying.

## Usage

Open `index.html` in any modern web browser. No build step or server required — the site is fully static.

## Customization

- Edit `styles.css` for global styling and theme colors (CSS variables in `:root`)
- Edit `page.css` for inner page styles
- Update placeholder values (address, phone, email, bank details) in the HTML files
- Replace images (`.jpg` files) with your own
- Update canonical URLs and schema.org data with your domain before deploying
